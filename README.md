# 발췌 스튜디오 1.1.2 (크롬 확장)

아무 웹페이지에서 드래그한 글을 **발췌 카드**로 꾸며 PNG로 저장하는 크롬 확장(Manifest V3)입니다. 형광펜·밑줄·검열·단어 치환·종이 질감 배경·작품명 표기를 지원합니다. 마리나라용 [marinara-excerpt-studio](https://github.com/boricha417/marinara-excerpt-studio)를 브라우저 확장으로 옮긴 판이며, 카드 편집 기능은 같습니다.

## 설치

스토어에 올리지 않은 확장이라 압축을 풀어 직접 로드합니다. 크롬·엣지·웨일 모두 같은 방법입니다.

1. 저장소에 올려 둔 `발췌 스튜디오 웹확장_v1.1.2.zip`을 받아 폴더로 풉니다(`manifest.json`, `background.js`, `content.js`, `styles.js`, `icon128.png`). 저장소 전체를 "Download ZIP"으로 받았다면 안쪽 폴더를 씁니다.
2. 주소창에 `chrome://extensions`(엣지는 `edge://extensions`)를 열고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 위 폴더를 고릅니다.
4. 툴바의 퍼즐 아이콘에서 발췌 스튜디오를 **고정**해 두면 한 번에 누를 수 있습니다.

업데이트할 때는 폴더 내용을 바꾼 뒤 확장 페이지에서 새로고침 버튼을 누릅니다.

## 사용 순서

1. 페이지에서 글을 **드래그**한 뒤 툴바의 **발췌 스튜디오 아이콘**을 누릅니다. 페이지 위에 떠 있는 버튼은 없습니다.
2. 글을 선택하지 않고 아이콘을 누르면 **붙여넣기 모드**가 열립니다. 글을 붙여 넣고 `이 글로 발췌 시작`을 누르면 같은 편집 창이 열립니다. 드래그가 막힌 사이트나 다른 앱의 글을 가져올 때 씁니다.
3. 미리보기에서 글자를 드래그한 뒤 형광펜·밑줄·검열 색을 고르면 그 부분에 마크가 들어갑니다.
4. `PNG 저장`을 누르면 `발췌_날짜_시각.png`로 다운로드됩니다.

## 설정 항목

| 묶음 | 항목 |
| --- | --- |
| 글자 | 크기(슬라이더 또는 숫자 직접 입력), 폰트, 정렬(왼쪽·가운데·오른쪽·양쪽), 글자색, **대사 색상**(따옴표 "…" 안의 글만 다른 색, 켜고 끄기) |
| 형광펜 · 밑줄 · 검열 | 형광펜 4색(노랑·초록·분홍·파랑) + 직접 선택 1색, 밑줄은 같은 색을 짙게, 검열(검은 마크), 마크 지우기. 형광펜↔밑줄은 모드 버튼으로 전환합니다. 직접 선택 견본은 모서리의 `C` 뱃지를 누르면 색을 고를 수 있고, 고른 색은 기억되며 그 견본으로 칠한 부분은 색을 바꾸면 같이 바뀝니다. |
| 치환 | `찾기 → 바꾸기` 규칙을 여러 개 둡니다. 마크는 바뀐 글 위치를 따라가고, 따라갈 수 없는 마크는 사라지며 안내가 뜹니다. |
| 작품 정보 | **캐릭터 이름**(기본 비움, 직접 입력)과 **플랫폼**(사이트의 `og:site_name`을 읽어 채우고, 없으면 주소의 호스트명). 둘 다 고쳐 쓸 수 있고, 사이트마다 다시 읽으므로 저장하지 않습니다. |
| 배경 | **질감 4종** 화이트·다크·크림·크라프트 × **무늬 4종** 종이 질감·줄노트·모눈·없음, 또는 **단색**, 또는 **기기 이미지**(불러온 뒤 어둡게·밝게 겹치기 가능) |
| 카드 | 폭, 모서리 둥글기(기본 16px), 높이 자동/직접, 직접일 때 본문을 위쪽/가운데 정렬 |

설정은 확장 저장소(`chrome.storage.local`)에 저장되어 어느 사이트에서 열어도 같습니다. 이미지 배경과 작품 정보는 저장하지 않습니다.

## 폰트

| 항목 | 출처 |
| --- | --- |
| 기본 (페이지 폰트) | 지금 보고 있는 페이지의 글꼴 그대로 |
| Pretendard, 리디바탕, 고운돋움, 나눔고딕, 나눔명조, IBM Plex Sans KR, Noto Sans KR | 기기에 설치되어 있으면 그것을 쓰고, 없으면 jsDelivr CDN에서 한 번 내려받아 등록합니다. 전부 무료 배포 폰트입니다. |
| 기기 폰트 직접 입력… | 설치된 폰트 이름을 적습니다(예: KoPubWorld돋움체). |

사이트의 보안 정책(CSP)이 페이지 안에서 폰트 파일을 받는 것을 막으면, 백그라운드 서비스 워커가 대신 받아 전달합니다. 중계는 `fastly.jsdelivr.net` 주소만 허용합니다.

## 권한 설명

| 권한 | 쓰는 곳 |
| --- | --- |
| `activeTab`, `scripting` | 아이콘을 **누른 탭에만** 그 순간 편집 창을 주입합니다. "모든 사이트의 데이터 읽기" 경고가 뜨지 않는 조합입니다. |
| `storage` | 카드 설정 저장 |
| `https://fastly.jsdelivr.net/*` | 웹폰트 내려받기 |

편집 창은 **Shadow DOM** 안에 격리되어 사이트의 CSS와 섞이지 않고, 사이트 쪽에서도 편집 창의 내용을 건드리기 어렵습니다. 페이지에 미리 심어 두는 코드는 없고, 아이콘을 누르기 전에는 아무것도 실행되지 않습니다.

## 알아둘 점

- `chrome://` 페이지, 웹 스토어, 브라우저 내장 페이지에서는 확장이 코드를 넣을 수 없어 아이콘을 눌러도 열리지 않습니다. 이런 곳의 글은 복사해서 붙여넣기 모드로 가져오세요.
- 미리보기 안에서 글자를 선택할 때 Shadow DOM 전용 API를 쓰므로 크로미움 계열 브라우저 기준입니다. 파이어폭스는 확인하지 않았습니다.
- 저장되는 PNG는 미리보기와 같은 배치로 캔버스에 다시 그린 것입니다. 폰트가 아직 로드 중이면 저장이 잠시 기다립니다.
